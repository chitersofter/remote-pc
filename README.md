# Remote PC

Пульт для управления Windows-компьютером с телефона. В проект входят сервер на Python, веб-интерфейс и Android-приложение на Flutter.

Через пульт можно управлять мышью и клавиатурой, медиа, громкостью и яркостью, запускать приложения и отправлять команды. Есть голосовой ввод, Telegram-бот и локальный ИИ на базе Qwen для обработки запросов.

## Важно перед запуском

Сервер принимает подключения из сети и позволяет управлять компьютером и выполнять команды PowerShell. В этой версии нет полноценной авторизации для HTTP-запросов: любой, кто может подключиться к серверу, может получить управление компьютером. Не открывайте порты в интернет и используйте приложение только в доверенной, изолированной сети. HTTPS с самоподписанным сертификатом сам по себе не ограничивает доступ.

## Запуск на Windows

Установите Python 3.12 и зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Веб-пульт доступен по адресу `http://<IP-компьютера>:5000`. HTTPS для браузерного микрофона запускается на порту 5001 с автоматически создаваемым самоподписанным сертификатом. Телефон и компьютер должны иметь сетевую связность.

Для Telegram-бота задайте свой токен перед запуском:

```powershell
$env:REMOTE_PC_BOT_TOKEN = "токен-вашего-бота"
.\.venv\Scripts\python.exe app.py
```

Без токена веб-пульт запускается без Telegram-бота. Не сохраняйте токен в коде и не публикуйте `users.txt`, `key.pem` и `cert.pem`.

## Локальный ИИ

Код поддерживает локальный `llama-server` с моделью Qwen 2.5 1.5B в формате GGUF. Файлы модели и движка в репозиторий не включены: для этого режима их нужно установить отдельно в `ai_runtime/`. Есть запасной вариант с `torch` и `transformers` — эти необязательные зависимости перечислены в `requirements.txt`.

## Android

Исходники приложения находятся в `mobile_app/`. Установите Flutter и Android SDK, затем выполните:

```powershell
cd mobile_app
flutter pub get
flutter run
```

Готовый APK и ключ подписи в репозиторий не включены. Для подписанной release-сборки настройте собственный ключ подписи Android.

## Файлы проекта

- `app.py` — сервер и команды управления.
- `ai_agent.py` — локальный ИИ и обработка команд.
- `templates/` — веб-пульт.
- `mobile_app/` — приложение Flutter для Android.
- `test_suite.py`, `test_ai_and_fixes.py` — тесты проекта.
